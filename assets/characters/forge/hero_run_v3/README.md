# Hero Run v3 — grounded

向右貼地小跑，8 幀、12 FPS。來源是 image_gen 逐幀關鍵姿勢，再經 Agent Sprite Forge 的網格讀取、去背、master 色盤鎖定、註冊、pixel 完成、步態及循環檢查。沒有使用影片生成。

每格 128×128，遊戲以 nearest 放大 4 倍為 512×512。主角中立比例沿用 v2：全身 90、頭含髮髻 40、腰至鞋底區段 32。第 2、6 幀身體低 1 像素，第 3、7 幀高 2 像素；腳不離地，所以實際外框高度依序是 90、89、92、90、90、89、92、90。沒有把每幀全身外框各自縮放成相同高度。

腳底錨點 `(64,109)` 採 0 起算、最後一個有像素的落地列；其下緣是 y=110，故 Forge 完成工具使用 `(64,110)`。每幀至少一隻腳在第 109 列；另一腳最多離地 5 像素。第 4、8 幀為貼地換腿，準備落地的鞋底在第 106 列。近側腿較淺、遠側較深，兩個半循環交替。

八幀的頭髮及髮髻各有獨立的 image_gen 來源；頭髮輪廓移除平移後，28 組兩兩比較全部不同。保留 master 的臉部小區域，沒有複製整顆頭。登錄階段對髮量過寬使用共用 0.9 水平網格校準，並只在上部頭髮增刪 -1 至 2 個既有整列像素，使每幀頭部維持 40 高；五官區域不做縮放。每幀自己的髮絲尖刺在完成工具後獨立保留。詳見 `provenance.json` 及 `qa/registration.json`。

- `run-strip.png`：1024×128，八格橫排。
- `run-strip-4x.png`：4096×512，整數 4× 放大。
- `clips/frames/`：八張 128×128 RGBA PNG。
- `animation.json`：12 FPS、共用錨點、每幀起伏與腳底列。
- `run.gif`：512×512 透明預覽。GIF 只能以 10 ms 計時，此循環 670 ms；精確 12 FPS 請依 JSON 的 5/60 秒節拍播放。
- `run.webp`：Forge 無損透明預覽，667 ms，解碼像素與時間經檢查。
- `qa/`：最終逐幀尺寸、兩腳落地、頭髮輪廓、色盤、pixel 完成、步態、循環及已解決的中間警示。

全套可見色數 26，只使用 master 26 色；透明度只有 0/255，無抗鋸齒或漸層。Forge 最終檢查無警示：軀幹漂移 0.88 px，最大相鄰變化比 1.35，8→1 接點比 0.691，均符合 1.5 上限。

`gait_loop.py` 最少需要 12 幀輸入，分析時將原本八張圖重複三個循環，工具選回 [0,8)；成品只保留原八幀。因使用者要求全程貼地，步態檢查採 walk 的接地規則，素材動作仍命名 `run_right`。沒有 ping-pong 或補間合成。

本資料夾只新增成品。master、v2 及其他既有檔案未修改，既有檔案 SHA-256 列於 `provenance.json`。
