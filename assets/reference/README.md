# 美術參考圖

給 Codex / 美術生成素材時附上的風格參考。**只作風格參考，不可複製其中任何建築、人物、招牌或道具的具體造型。**

| 檔案 | 用途 |
|---|---|
| `town_style_ref.png` | 鎮內風格參考：色調（低彩度、偏暗、深綠與灰褐）、霧氣陰天氣氛、像素顆粒感 |
| `../characters/hero_front.png` | 主角正面：角色畫風與頭身比（約 2.5 頭身 Q 版）參考 |
| `../characters/hero_side.png`、`../characters/hero_back.png` | 主角側面、背面 |
| `../templates/walk_*_template.png` | 走路姿勢模板（灰色人偶，4 格 2048×512），用來套定裝照出走路圖 |

指令寫法範例：「參考 assets/reference/town_style_ref.png（只取色調、氣氛、像素顆粒感）與 assets/characters/hero_front.png（只取畫風與頭身比），重新設計，不要複製造型。」
